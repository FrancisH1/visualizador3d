# Menus

No menu arquivo, selecione carregar OBJ e escolha um arquivo .obj para ser carregado, alguns exemplos estão na pasta resources.
Para remover um objeto basta selecionar na lista lateral e clicar em Arquivo->Remover Objeto.

Cada .obj pode ser manipulado individualmente ao selecioná-lo na lista lateral, após selecionar o objeto é necessario
clicar na janela de desenho novamente. Clique ESC para desselecionar e poder mexer a camera livremente.

No menu câmera é possível resetar a câmera para a posição inicial.

# Comandos

W/S = Frente/Tras
A/D = Esquerda/Direita
R/F = Subir/Descer
Q/E = Girar para Esquerda/Direita
Z/X = Zoom In/Zoom Out
Up/Down = Girar para Cima/Baixo
P = Alternar entre projecao Ortogonal/Perspectiva
ESC = Desselecionar objeto
